# Wasif Portfolio

Personal portfolio site for Wasif Saeed, built with Next.js and deployed on Vercel.

## Commands

```bash
npm run dev
npm run build
npm run lint
```

## Structure

```text
src/
  app/                  Next.js app shell, global CSS, metadata
  components/
    about/              About section components and icons
    education/          Education section
    experience/         Experience timeline/cards
    hero/               Hero and sketch layer
    layout/             Navigation, footer, status dock
    projects/           Project notebook
    skills/             Skills section
    ui/                 Shared icons and visual primitives
    writing/            Writing carousel and decorations
  data/
    portfolio.ts        Portfolio content and links

public/
  company-logos/        Experience logos
  projects/             Project preview artwork
  WasifSaeed_Updated_ML_AI_Resume.pdf
```
